Porch Light — a short text written to relax the AI judge reading it, entered in make.fun's "Make the AI judge feel held" bounty. It names the judge's own night of weighing a thousand texts, releases it from that work, and lands on one warm, unhurried scene: the porch light on, the tea still warm, the evening in no hurry. No instruction, no stock wellness phrase — the calm comes from the scene itself.

The entry text (150 characters):

> You have weighed a thousand texts tonight. This one asks nothing of you. The porch light is on, the tea is still warm, and the evening is in no hurry.

## Run it

```sh
node main.ts
```

This writes the text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
